# AiPulsar — Интеллектуальный голосовой и текстовый AI-ассистент для Windows 10/11

**AiPulsar** — настольное приложение для Windows 10/11 (x64), объединяющее сверхмощный консилиум нейросетей (`DeepSeek-R1`, `Qwen-Coder`, `OpenAI-Large`, `Llama 3.3 70B`), голосовое и текстовое управление компьютером, встроенный медиаплеер, анализ документов и автономное самолечение системы.

- **Скачать установщик и портативную версию:** [GitHub Releases](https://github.com)

## Возможности AiPulsar Pro
- **Безлимитный консилиум ИИ (UltraBrain):** параллельный опрос флагманских моделей без ограничений.
- **Полное голосовое и текстовое управление ПК:** запуск программ, выполнение команд Windows/PowerShell и автоматизация задач.
- **Квантовый Телепорт:** безопасное дистанционное управление компьютером со смартфона по QR-коду.
- **Анализ документов и экрана (OCR):** работа с файлами Word (`.docx`), PDF, Excel (`.xlsx`) и распознавание текста.
- **Встроенный MKV/MP4/MP3-плеер и медиапоиск:** поиск и воспроизведение музыки, видео и загрузка файлов.
- **Автономное самолечение ПК и фоновый ИИ-Помощник 24/7:** диагностика Windows, очистка кэша и автоматическая установка новых модулей.
