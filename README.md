# AiPulsar — Интеллектуальный голосовой и текстовый AI-ассистент для Windows 10/11

**AiPulsar** — настольное приложение для Windows 10/11 (x64) с функциями ИИ-ассистента, голосового управления, встроенного медиаплеера, анализа документов и диагностики системы. Полный текст описания, ссылки на релизы (`Setup_AiPulsar.exe` и `AiPulsar_Windows.zip`), тарифы (Pro — 490 ₽ за 1 месяц и 1 990 ₽ за 1 год), а также контакты разработчика (VESKOR / Смирнов В.Е., veskor.dev-2026@yandex.ru) и условия возврата средств размещены в файле репозитория [GitHub](https://github.com).
